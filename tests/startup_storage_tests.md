Run `./tests/run_startup_storage_tests.sh` with Xcode and an installed iOS Simulator runtime. The runner compiles the complete production AppDelegate (including its storage-error view) and the actual SceneDelegate preference method. Small doubles replace unrelated application services, normal storyboard contents and external-display routing. A test coordinator injects disk-full and permission errors; the successful retry attaches a real SQLite store containing a saved host.

The fixture checks that failed opening never publishes an empty coordinator/context, never loads normal app UI or services, never constructs an external-scene DataManager, and never deletes or resets the SQLite file or sidecars. Repeated getters stay failed without looping. Retry performs one new attempt, handles another failure, then recovers the original saved host. Storage-ready notification precedes external preference recovery. A retained Retry action cannot rebuild an already recovered UI.

An isolated landscape simulator is created and deleted automatically. Live console/build diagnostics remain under `Build/startup-storage-tests/<run>/`; an external 90-second timeout catches startup deadlocks. Database and sidecar sentinels are fixture-owned and never touch the user's app. Environment variables `STARTUP_STORAGE_TEST_RUNTIME` and `STARTUP_STORAGE_TEST_DEVICE_TYPE` can select an installed simulator runtime/device. No generated binaries or store files are tracked.
