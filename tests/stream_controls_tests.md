Run `./tests/run_stream_controls_tests.sh` with Xcode and an installed iOS Simulator runtime. The test app is locked to landscape. The runner creates and deletes an isolated simulator, builds the actual UIKit overlay and flat PC settings form, and captures console output. It does not connect to a PC or launch the user’s app.

The collapsed phone surface contains one App settings pill. All other space passes through to the existing touch/gamepad input system, including tap-to-click. Paused-touch guidance points to that PC’s settings. The pill opens four fixed tabs directly: 2D, Host 3D, Client 3D, and Raw SBS. The header names the app. No Session hub, input/sound page, keyboard action, or persistent PC/Global link appears inside the overlay.

Each usable tab contains Resolution and Max frame rate menus, an inline Max bitrate slider, Restore defaults, and its own Apply & reconnect. Labels retain text alongside the original Moonlight 3D vectors; separators divide the groups. The shared palette uses the Android surface, accent, text, and danger tokens. There is no second-level picture-quality page. The owner supplies the selected app/PC/mode draft and pending flag, stages quality callbacks, and persists only on explicit Apply. Arbitrary saved dimensions, frame rates, and bitrates remain unchanged when opened. Host presets follow the host model contract. Raw’s complete glasses resolution is legible static information with a lock; FPS and bitrate remain editable. The owner’s frame-rate ceiling limits new choices without silently rewriting the stored value. The bitrate slider supports 500 Kbps and retains existing values above its usual range.

Restore defaults stages removal of only that app’s selected mode override on that PC and inherits global quality after Apply. Client 3D is browse-only until iOS 27 verification. Legacy active Raw Half normalizes to canonical Raw, with no Full/Half controls. Four explicit tabs require no separate remembered source preference. Missing 3D hardware disables Host/Raw until an explicit available choice.

End session appears exactly once in a divider-separated common footer inside App settings, outside the mode body. Close/scrim discard staged edits and return to pass-through input. Tests verify explicit reconnect and reset callbacks, no setter echo or navigation on quality edits, native menu selection, pending cancellation, stale menu/slider rejection after tab switches or Close, accessibility slider editing, and reuse of menus during bitrate drags/input refresh. Tabs, header, and common footer stay fixed while the body scrolls. Landscape, portrait, iPad-sized views, and maximum Dynamic Type are covered.

Shared PC settings belong on the app list. Their flat native form stages shared streaming, control mode, touch, local volume, and statistics together in separated groups, without child pages. Tests verify original-model isolation, exact reset-to-global copies, edit-after-reset behavior, one combined Save callback, and Cancel. Cancel and interactive page-sheet dismissal retire the editor: retained slider/reset/Save events cannot submit an abandoned draft, and closing callbacks run once. Per-app picture quality stays separate. Global settings belong on the machine list and are verified through the actual app’s dedicated settings-navigation fixture, rather than obsolete index or nested quality controllers.

Console output, build diagnostics, and UIKit screenshots are stored in `Build/stream-controls-tests/<run>/`. Generated binaries and images must not be tracked. Use `STREAM_CONTROLS_TEST_OVERLAY_ONLY=1` for App settings/input-isolation/layout checks, or `STREAM_CONTROLS_TEST_SHARED_ONLY=1` for the flat native PC form. Optional `STREAM_CONTROLS_TEST_RUNTIME` and `STREAM_CONTROLS_TEST_DEVICE_TYPE` select an installed simulator runtime and device type.

Icon provenance: `SunlightMoonlightIcons` preserves the 24×24 paths and stroke attributes from Moonlight 3D’s `app/src/main/res/drawable/ic_xr_*.xml`, plus `ic_settings.xml` and `ic_computer.xml`. Tab labels come from `values/strings.xml` (`xr_bar_*`); palette roles from `values/colors_xr.xml`; selected tile styling follows `XrStreamPresenter.BarItem.setSelected`. The iOS-requested 2D/Host/Client/Raw order is retained. The fixture checks cached template rendering for every imported icon, the exact accent token, labelled tab interactions, and no clipping of the four tabs in standard landscape. The sibling Android repository is read-only; the fixture does not access or build it.
