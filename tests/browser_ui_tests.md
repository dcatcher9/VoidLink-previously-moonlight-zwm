Run `./tests/run_browser_ui_tests.sh` on a Mac with Xcode and an installed iOS Simulator runtime. This promotes the former ignored `build/ui-card-tests` fixture into a repeatable source test. The runner compiles the complete production `UIAppView.swift`, `HostCardView.swift`, and `HostCollectionViewController.swift` with the real theme/icon catalog. Test doubles replace host metadata, asset-path lookup and navigation collaborators; UIKit views, layouts, timers and image decoding are real.

Coverage includes a fitting host grid, overflow, removal back to one host, parent shrinking/growing, an empty list, and reuse under a new parent. Required bottom-equality constraints must not survive these transitions. App aspect-ratio queries must agree with real view bounds and avoid all artwork lookups. Existing artwork replacement, eviction, deletion and placeholder tests remain, as do one active timer after reattachment, cancellation on detach, and playing/stopped image opacity.

The fixture has no networking or pairing code and never launches the user's app. It creates and deletes a dedicated landscape simulator, preserving live console output and build diagnostics under `Build/browser-ui-tests/<run>/`. An external 90-second timeout catches UI deadlocks. Optional `BROWSER_UI_TEST_RUNTIME` and `BROWSER_UI_TEST_DEVICE_TYPE` select an installed runtime/device. No generated binaries, simulator state or image files are tracked.
